# CONTEXT — 华夏志 (Huaxia History)

## 项目定位

一个电影级沉浸体验的中国历史时间线可视化网站。打开网站的瞬间像观看电影预告片，随后进入精致的内容阅读体验。学术级数据可靠性 + 大众级视觉感染力。

---

## 核心体验原则

1. **首屏是预告片** — 打开即沉浸，像《长安三万里》片尾般的视觉冲击
2. **内容页是阅览室** — 实用信息为主，极简为骨，氛围为魂
3. **搜索是时光机** — 输入关键词，整个界面像电影镜头调度一样推你到那个时空坐标
4. **导航是坐标仪** — 告诉你当前在"哪朝哪代"，而非罗列功能菜单
5. **过渡是演出** — 暗→亮不是切换，而是一滴墨晕开的 1.2 秒光影演出

---

## 视觉风格

### 整体架构
- **首屏**：深色电影场景（缓慢平移的古代高清复原CG / 超宽古画卷轴）
- **内容页**：浅色阅读底色（宣纸质感）
- **过渡**：墨滴晕染动画（1.2s，墨滴落下→晕染扩散→透明度渐增→亮色浮现）

### 色彩体系
- **首屏**：暗调画面，文字用极细上缘渐变遮罩（非全黑底）
- **内容页底色**：浅暖白（宣纸感）
- **朝代氛围色**：每个朝代有独特的环境色调（唐暖金、宋天青、明赭石等），用于卡片边框、标记点、高亮状态
- **墨色**：用于水墨晕染动效（深褐/灰黑，非纯黑）
- **主强调色**：秦汉朱砂红 `#c9372c`
- **辅强调色**：唐宋鎏金黄 `#d4af37`

### 字体
- **标题**：思源宋体 Heavy（有历史温度的现代宋体）
- **正文**：思源宋体 Regular
- **英文**：Source Serif Pro
- **年份/数字**：JetBrains Mono（等宽，便于对齐）
- **装饰**：ZCOOL XiaoWei、Ma Shan Zheng（极少使用）

## 页面与交互

### 首屏 (Hero)
- 全视口电影画面，缓慢水平平移（类似纪录片片头）
- 中央大标题 "华夏志 · 史" + 印章装饰，上缘渐变遮罩保障可读性
- 向下滚动箭头引导
- 无多余控件，画面绝对主导

### 过渡动画
- 从首屏滚动进入内容页时触发墨滴晕染过渡
- 墨滴从画面中央落入，向四周晕开，同时透明度渐增，露出浅色内容页
- 时长 1.2s：前 0.4s 墨滴落下，后 0.8s 晕染+透明化

### 时间线
- **极简实用**：一条干净的中轴线，年份刻度，事件卡片左右交替排列
- **电影点缀**：当前视口中央的事件卡片有轻微"对焦"效果（周围轻微虚化）
- **数据展示**：精选事件默认展示，点击"查看全部"展开完整列表
- **范围**：夏商周（约 BC2070）至清（1912），全史贯通
- **密度分层**：唐/宋/明/清为 rich（20+事件、30+人物），其余为 thin（5事件、5人物）
- **事件筛选**：政治/军事/文化/科技分类筛选（v1.0 包含）

### 地图系统
- **底图**：现代矢量地图（Mapbox Light / CartoDB Positron），清晰、加载快
- **核心功能**：让历史书里的地名落地生根，城镇数据覆盖度优先
- **标记**：都城、州治、关隘，精确坐标 + 古今地名对照
- **转场动画**：点击朝代/事件后，地图从全览视角平滑飞行到目标城市（电影镜头感）
- **动态疆域**：时间滑块控制疆域 polygon 变化（v1.0 包含）
- **历史路线**：丝绸之路、大运河等路线动画（v1.0 包含）

### 朝代详情页
- **单页长卷**：一页到底，像一篇精心排版的朝代传记
- **内容结构**：顶部大图/氛围色块 → 基本信息（起止、国祚、都城）→ 精选关键事件（≥5）→ 精选代表人物（≥5）→ 年号速查表 → "查看全部"展开完整数据
- **无标签页切换**，滚动即阅读

### 人物详情页
- **侧重关系图谱/网络可视化**：人物为中心节点，展示同期关联人物网络
- 单页长卷，基本信息 + 关系图谱 + 生平简介 + 代表作品

### 搜索
- **时空联动**：搜索"安史之乱"后，时间线自动滑动到 755 年并高亮，地图飞行到潼关/长安，右侧浮出详情面板
- **镜头调度动画**：0.5-1s 的地图飞行+时间线滑动+面板展开，非瞬间跳转
- 搜索框始终可用，随时切换关键词

### 导航栏
- **上下文智能导航**：不罗列功能菜单，而是显示当前焦点对象
  - 时间线页：「唐 · 618-907」
  - 地图页：当前查看的城市/区域名
  - 人物页：人物姓名 + 朝代
- 始终有「返回」箭头和搜索图标
- 不同页面高度/内容可不同

## 动效语言

### 水墨晕染（内容页主力）
- 元素出现：淡入 + 轻微扩散（墨入清水）
- hover 反馈：墨色加重（非放大）
- 页面切换：前页墨化淡出，后页水墨渐显

### 现代物理（空间交互主力）
- 首屏粒子/云层动画
- 地图缩放飞行（加速→减速，有质量感）
- 时间线滚动（惯性阻尼）

---

## 移动端

- **原生移动体验**，非桌面缩小版
- 首屏：全屏电影画面，向上滑动才看到标题（抖音式上滑交互）
- 时间线：纵向滚动（微信时间线式），每个朝代是可横向滑动的卡片
- 地图：标准双指缩放（高德/百度式）
- 搜索：底部固定搜索栏，点击全屏展开
- 详情页：微信公众号文章式单栏长滚动

---

## 数据架构（不可变契约）

### 数据源形态
- v1.0 使用静态 JSON 文件
- **但数据结构按未来 API 返回格式设计**，未来接入 CBDB/CHGIS 时只替换 `dataLoader.ts`，页面零改动

### 增量加载
- v1.0 实现虚拟滚动（只渲染视口内元素）
- 未来数据量增加时自动受益，无需改动

### 数据丰富度字段
- 每个朝代对象含 `richness` 字段：`thin` / `medium` / `rich`
- 页面根据此字段自动决定展示多少内容、开启动态疆域还是仅显示都城
- 后期将某朝代从 `thin` 改为 `rich`，页面自动变厚，零代码改动

## 术语表

| 术语 | 定义 |
|:---|:---|
| **时空联动搜索** | 搜索关键词后，时间线、地图、详情面板三组件同步移动定位到目标时空坐标 |
| **镜头调度** | 地图飞行 + 时间线滑动 + 面板展开的协同动画，模拟电影镜头运动 |
| **墨滴晕染** | 暗色首屏向浅色内容页过渡的核心动画：墨滴落入→晕染扩散→透明化 |
| **richness** | 朝代数据丰富度标记：`thin`(5事件/5人物) / `medium` / `rich`(20+事件/30+人物) |
| **对焦效果** | 时间线中当前视口中央卡片轻微清晰、周围轻微虚化的视觉处理 |
| **氛围色** | 每个朝代独有的环境色调（唐暖金、宋天青等），用于卡片、标记、高亮 |
